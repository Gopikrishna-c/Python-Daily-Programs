# ➕➖ Positive, Negative or Zero Checker

## 📌 Description

This Python program accepts a number from the user and checks whether it is **Positive**, **Negative**, or **Zero** using conditional statements.

---

## 🛠️ Technology

- Python

---

## 📚 Concepts Used

- Variables
- User Input
- If, Elif, Else
- Comparison Operators (`>`, `<`, `==`)
- For Loop

---

## 💻 Sample Output

```text
*****Positive, Negative or Zero Checker*****

Enter the number :5
5 Is a Positive Number

Enter the number :-4
-4 Is a Negative Number

Enter the number :0
0 A Number is Zero
```
