# ⭕ Area of Circle using Python

## 📌 Project Description

This is a simple Python project that calculates the area of a circle based on the radius entered by the user.

The program uses the standard formula:

**Area = π × radius²**

The user enters the radius, and the program calculates and displays the area of the circle.

---

## 🚀 Features

- Calculate the area of a circle
- User-friendly input
- Beginner-friendly Python project
- Uses mathematical operations
- Uses Python's `math` module

## ▶️ How to Run

1. Open the project in Visual Studio Code.
2. Run the Python file.
3. Enter the radius of the circle when prompted.
4. The program will calculate and display the area.
