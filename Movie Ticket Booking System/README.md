# 🎬 Movie Ticket Booking System

## Description

A simple Python program that allows users to book movie tickets, view booked movies, and exit using a menu-driven approach.

## Technology

- Python

## Concepts Used

- Lists
- `append()`
- `while` Loop
- `for` Loop
- User Input
- `if-elif-else`
