# 🔍 List Item Search

## Description

A simple Python program that checks whether an item is available in a list.

## Technology

- Python

## Concepts Used

- Lists
- User Input
- `in` Operator
- `if-else`
- `lower()`

## Sample Output

```text
***** List Item Search *****
Enter an item: Apple
Item found in the list!

***** List Item Search *****
Enter an item: Grapes
Item not found in the list!
```
