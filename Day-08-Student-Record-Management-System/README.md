# Student Record Management System

## Description
Student Record Management System is a simple Python project that uses File Handling to store and manage student records. Users can add new student details and view all saved records through a menu-driven interface.

## Features
- Add new student records
- View all stored student records
- Store data in a text file
- Menu-driven application
- Beginner-friendly project

## Technologies Used
- Python

## Project Files
- `student_records.py` – Main Python program
- `students.txt` – Stores student records
- `README.md` – Project documentation

## Concepts Covered
- File Handling
- Functions
- Read and Write Operations
- Menu-Driven Programming
- Exception Handling

## Sample Student Record

```text
Name: Gopi, Age: 22, Course: Python
Name: Rahul, Age: 21, Course: Java
Name: Priya, Age: 20, Course: Data Science
```

## How to Run

1. Open the project in Visual Studio Code.
2. Run the Python file:

```bash
python student_records.py
```

3. Select an option from the menu:
- Add Student
- View Students
- Exit

## Output

The program stores student details in `students.txt` and displays them whenever the user selects the **View Students** option.
