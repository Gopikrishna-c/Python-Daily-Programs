# 💰 Expense Tracker using Python

## 📌 Project Description

This is a simple Python project that helps users track their daily expenses. The program allows users to enter multiple expense amounts, stores them in a list, displays each expense, and calculates the total amount spent.

---

## 🚀 Features

- Enter multiple expense amounts
- Store expenses using a Python list
- Display all entered expenses
- Calculate the total expense
- Beginner-friendly command-line application

---

## 🛠️ Technology Stack

## 📚 Python Concepts Used

- User Input
- For Loop
- List Methods (`append()`)
- Built-in Functions (`sum()`, `len()`)
- String Formatting (f-strings)

---

## ▶️ How to Run

1. Open the project in Visual Studio Code.
2. Run the Python file.
3. Enter the number of expenses.
4. Enter each expense amount.
5. View the expense list and total expense.
