# 🔢 Multiplication Table Generator using Python

## 📌 Project Description

This is a simple Python project that generates the multiplication table of a number entered by the user. The program uses a **for loop** to display the multiplication table from **1 to 10**.

---

## 🚀 Features

- Accepts a number from the user
- Displays the multiplication table from 1 to 10
- Beginner-friendly Python project
- Simple command-line application

---

## 🛠️ Technology Stack

- Python

---

## 🧰 Tools Used

- GitHub

---

## 📚 Python Concepts Used

- Variables
- User Input
- For Loop
- Arithmetic Operators
- String Formatting (f-strings)

---

## ▶️ How to Run

1. Open the project in Visual Studio Code.
2. Run the Python file.
3. Enter a number.
4. The program displays the multiplication table from 1 to 10.
