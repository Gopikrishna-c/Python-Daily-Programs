# 🔢 Even or Odd Checker

## 📌 Description

This Python program checks whether the entered number is **Even** or **Odd** using the modulus (`%`) operator and `if-else` condition.

---

## 🛠️ Technology

- Python

---

## 📚 Concepts Used

- Variables
- User Input
- If-Else
- Modulus Operator (`%`)

---

## 💻 Sample Output

### Example 1

```text
*****Even or Odd Checker*****

Enter the Number:4

Is a Even Number
```

### Example 2

```text
*****Even or Odd Checker*****

Enter the Number:5

Is a Odd Number
```
