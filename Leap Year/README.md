# 📅 Leap Year Checker using Python

## 📌 Project Description

This is a simple Python project that checks whether a given year is a **Leap Year** or **Not a Leap Year** using a function. The program accepts a year from the user, applies the leap year rules, and displays the result.

---

## 🚀 Features

- Accepts a year from the user
- Checks whether the year is a Leap Year or Not a Leap Year
- Uses functions for better code organization
- Beginner-friendly command-line application

---

- Python

- Modulus Operator (`%`)

## ▶️ How to Run

1. Open the project in Visual Studio Code.
2. Run the Python file.
3. Enter a year.
4. The program checks whether the year is a Leap Year or Not a Leap Year.
