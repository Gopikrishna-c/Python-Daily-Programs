# 📧 Email Validator using Python

## 📌 Project Description

This is a simple Python project that validates whether an email address entered by the user follows a basic email format.

The program checks:
- Presence of exactly one `@` symbol.
- Presence of a `.` after the `@`.
- Email should not start with `@`.
- Email should not contain spaces.
- Email should not end with a `.`.

If all the conditions are satisfied, the program displays **"Valid Email"**; otherwise, it displays **"Invalid Email"**.
