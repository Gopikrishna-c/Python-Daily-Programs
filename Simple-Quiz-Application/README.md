# Simple Quiz Application

## 📌 Project Overview
This is a simple Python quiz application that asks users three questions, checks their answers, and displays the final score.

## 🎯 Problem Statement
Develop a Python program that allows users to answer multiple questions and calculates their final score based on correct answers.

## ✨ Features
- Asks multiple quiz questions
- Accepts user input
- Checks whether the answer is correct
- Calculates and displays the final score
- Beginner-friendly Python project

## 🛠️ Technology Used
- Python 3

## 💻 Tools Used
- Visual Studio Code
- GitHub

## 📚 Concepts Used
- Variables
- User Input
- Conditional Statements (`if`, `else`)
- String Methods (`lower()`)
- Score Calculation
