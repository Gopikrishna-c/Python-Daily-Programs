# 🛒 Shopping List Manager

## 📌 Description

This Python program allows users to add items to a shopping list, view the list, and exit the program using a menu-driven approach.

## 🛠️ Technology

- Python

## 📚 Concepts Used

- Lists
- `append()`
- `while` Loop
- `for` Loop
- `if-elif-else`
- User Input
- Menu-driven Program
