# 🔍 Find Missing Number

## Description

A simple Python program that finds the **missing number** from a list of numbers ranging from `1` to `n`.

For example:

**[1, 2, 3, 4, 6, 7, 8, 9, 10]**

The missing number is **5**.

## Technology

* Python

## Concepts Used

* Lists
* `for` Loop
* Variables
* Arithmetic Operations
* Sum Calculation
* Problem-Solving Logic

## Sample Output

```text
***** Missing Number Finder *****
Numbers: [1, 2, 3, 4, 6, 7, 8, 9, 10]
Missing Number: 5
```
