🔢 Count Occurrences in a List

Description

A simple Python program that counts how many times a given number occurs in a list.

For example:

List → [10, 20, 10, 30, 20, 10, 40]

If the user enters 20, the number 20 appears 2 times.

Therefore, the number of occurrences is 2.

Technology

Python

Concepts Used

List

User Input

for Loop

if Condition

range() Function

Counter Variable

len() Function

Sample Output

*****Count Occurrences*****

List: [10, 20, 10, 30, 20, 10, 40]
Enter the number: 20
Occurrences: 2
