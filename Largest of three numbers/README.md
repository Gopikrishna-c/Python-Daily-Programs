# Largest of Three Numbers

## Description

Largest of Three Numbers is a simple Python project that accepts three numbers from the user and finds the largest number using **Nested if statements**. This project helps beginners understand decision-making and conditional logic in Python.

## Features

- Accepts three numbers from the user
- Compares the given numbers
- Finds and displays the largest number
- Uses nested if conditions
- Beginner-friendly Python project

## Technologies Used

- Python

## Project Files

- `largest_number.py` – Main Python program
- `README.md` – Project documentation

## Concepts Covered

- Variables
- User Input
- Nested if Statements
- Conditional Statements (if, else)
- Comparison Operators
- Decision Making
