# 🔢 Prime Number Checker using Python

## 📌 Project Description

This is a simple Python project that checks whether a given number is a **Prime Number** or **Not a Prime Number** using a function. The program accepts a number from the user, checks its divisibility using a loop and conditional statements, and displays the result.

---

## 🚀 Features

- Accepts a number from the user
- Checks whether the number is Prime or Not Prime
- Uses functions for better code organization
- Beginner-friendly command-line application

---

## 📚 Python Concepts Used

- Function Parameters

- For Loop
- Conditional Statements (`if`, `else`)
- Modulus Operator (`%`)
- User Input

---

## ▶️ How to Run

1. Open the project in Visual Studio Code.
2. Run the Python file.
3. Enter a number.
4. The program checks whether the number is Prime or Not a Prime Number.
