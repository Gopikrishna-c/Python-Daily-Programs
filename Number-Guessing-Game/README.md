# Number Guessing Game

## 📌 Project Overview
This is a simple Python project where the user tries to guess a secret number. The program checks whether the guessed number is correct and displays the appropriate message.

## 🎯 Problem Statement
Develop a Python program that allows the user to guess a secret number and informs whether the guess is correct or incorrect.

## ✨ Features
- Accepts user input
- Compares the guessed number with the secret number
- Displays success or failure message
- Beginner-friendly Python project

## 🛠️ Technology Used
- Python 3

## 💻 Tools Used
- Visual Studio Code
- GitHub

## 📚 Concepts Used
- Variables
- User Input
- Conditional Statements (`if`, `else`)
- Comparison Operators

## ▶️ Sample Output

### Correct Guess
```
************ Number Guessing Game ************

Guess the number (1-10): 7

🎉 Congratulations! You guessed the correct number.
```

### Wrong Guess
```
************ Number Guessing Game ************

Guess the number (1-10): 5

❌ Wrong guess!
The correct number is: 7
```
