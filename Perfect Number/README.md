# 🔍 Perfect Number Checker

## Description

A simple Python program that checks whether a given number is a **Perfect Number**.

A Perfect Number is a positive number that is equal to the sum of its proper divisors.

For example:

**28 → 1 + 2 + 4 + 7 + 14 = 28**

Therefore, 28 is a Perfect Number.
