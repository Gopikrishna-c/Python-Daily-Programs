# 🔤 Vowel Checker using Python

## 📌 Project Description

This is a simple Python project that checks whether the entered character is a **Vowel** or a **Consonant**. The program accepts a single character from the user, converts it to lowercase, and determines the result using a conditional statement.

---

## 🚀 Features

- Accepts a character from the user
- Checks whether it is a Vowel or Consonant
- Converts uppercase letters to lowercase automatically
- Beginner-friendly command-line application

---

## 🛠️ Technology Stack

- Python

---

## 🧰 Tools Used

---

## 📚 Python Concepts Used

- Variables
- User Input
- String Methods (`strip()`, `lower()`)
- Conditional Statements (`if`, `else`)
- Membership Operator (`in`)

---

## ▶️ How to Run

1. Open the project in Visual Studio Code.
2. Run the Python file.
3. Enter a single alphabet.
4. The program displays whether it is a **Vowel** or **Consonant**.
