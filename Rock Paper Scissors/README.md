Rock Paper Scissors
Description

Rock Paper Scissors is a simple Python-based command-line game where the user plays against the computer. The computer randomly selects Rock, Paper, or Scissors, and the program determines whether the user wins, loses, or the game is a draw.

Features
User can select Rock, Paper, or Scissors
Computer randomly selects a choice
Determines the winner automatically
Displays Draw when both choices are the same
Handles invalid user input
Beginner-friendly project
Technologies Used
Python

Logical Operators
String Methods
Game Rules
Rock beats Scissors
Scissors beats Paper
Paper beats Rock
Same choices result in a Draw
How to Run
Open the project in Visual Studio Code.
Open the terminal.
Run the Python file:
python main.py
Enter one of the following choices:
1.Rock
2.Paper
3.Scissors

Output

***** Rock Paper Scissors *****
