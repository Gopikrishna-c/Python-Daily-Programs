# 🔢 Armstrong Number Checker

## 📌 Description

This Python program checks whether the entered number is an **Armstrong Number** or **Not an Armstrong Number** using a while loop.

## 🛠️ Technology

- Python

## 📚 Concepts Used

- Variables
- User Input
- While Loop
- If-Else
- Modulus Operator (`%`)
- Arithmetic Operators

## 💻 Sample Output

### Example 1

```text
Armstrong Number Checker
Enter the number :153
Is an Armstrong Number
```

### Example 2

```text
Armstrong Number Checker
Enter the number :231
Is not an Armstrong Number
```
